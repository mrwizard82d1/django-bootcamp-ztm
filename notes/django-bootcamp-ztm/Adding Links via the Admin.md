Use Admin screen to add some links
- Start application
- Navigate to `/admin/`
- Click `Links` link

Add a single link
- Clink 'Add Link' button
	- Name: "Google"
	- URL: "https://www.google.com"
	- Slug: (Leave blank)
		- A blank will let the system automatically generate the slug
	- Count: 0
	- Click "SAVE" button

Review details of created link by clicking the link
